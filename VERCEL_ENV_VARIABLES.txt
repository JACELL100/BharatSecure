# Copy these environment variables to Vercel
# Go to: Vercel Dashboard → Your Project → Settings → Environment Variables

# ============================================
# REQUIRED ENVIRONMENT VARIABLES FOR VERCEL
# ============================================

# Backend API URL (REPLACE WITH YOUR RENDER URL AFTER BACKEND DEPLOYMENT)
VITE_API_URL=https://your-backend-name.onrender.com

# Supabase Configuration
VITE_SUPABASE_URL=your_supabase_url_here
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key_here

# ============================================
# IMPORTANT NOTES
# ============================================
# 1. Deploy backend to Render FIRST
# 2. Copy your Render backend URL (e.g., https://bharatsecure-backend.onrender.com)
# 3. Replace "https://your-backend-name.onrender.com" with your actual URL
# 4. Make sure there's NO trailing slash in VITE_API_URL
# 5. After adding these variables, deploy your frontend

# ============================================
# HOW TO ADD IN VERCEL
# ============================================
# 1. Go to Vercel Dashboard
# 2. Select your project
# 3. Click "Settings" tab
# 4. Click "Environment Variables" in left sidebar
# 5. Add each variable:
#    - Key: VITE_API_URL
#    - Value: https://your-backend-name.onrender.com
#    - Environment: Production, Preview, Development (select all)
# 6. Click "Save"
# 7. Repeat for other variables
# 8. Redeploy your project
